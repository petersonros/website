## Ponto de partida

Diferente de montar um projeto do zero, este guia parte do **mapa do labirinto e todos os sprites já prontos** (Pac-Man, fantasmas, pontinhos, telas) — desenhados e posicionados de antemão, pra focar em uma coisa por vez: **montar a lógica**, sem se perder desenhando ou procurando imagens.

O objetivo deste capítulo é só um: **fazer o Pac-Man andar pelo labirinto sem atravessar as paredes.**

## O que construímos

Dois scripts, os dois no sprite do Pac-Man:

### 1. Controlar a direção com o teclado

O controle aceita tanto as setas quanto WASD, pra ninguém ficar de fora por causa do teclado:

```
Quando a bandeira verde for clicada
Para sempre
  Se <seta para cima pressionada?> ou <tecla [w] pressionada?> então
    Aponte para direção (0)
  Se <seta para baixo pressionada?> ou <tecla [s] pressionada?> então
    Aponte para direção (180)
  Se <seta para direita pressionada?> ou <tecla [d] pressionada?> então
    Aponte para direção (90)
  Se <seta para esquerda pressionada?> ou <tecla [a] pressionada?> então
    Aponte para direção (-90)
```

### 2. Andar sem atravessar parede

```
Quando a bandeira verde for clicada
Para sempre
  Mova (20) passos
  Se <tocando na cor [preto]?> ou <tocando na cor [roxo]?> então
    Mova (-20) passos
  Espere (0.1) segundos
```

> 💡 **Dica:** o labirinto não é um sprite, é o **cenário** (o fundo). Então "bater na parede" não é tocar em outro sprite — é o Pac-Man checar a **cor** que tem embaixo dele. Se for a cor das paredes do labirinto, ele volta o passo que acabou de dar. É um truque simples, mas resolve o problema sem precisar de nada complicado.

## Por que dois scripts separados?

Por que não colocar tudo dentro de um script só? Os dois `Para sempre` rodam **ao mesmo tempo**, em paralelo — um cuida só de "pra que lado eu tô olhando", o outro cuida só de "andar pra frente e não atravessar parede". Separar deixa cada script simples de entender sozinho.

## O que ainda não existe nessa etapa

Pra deixar claro o estado real do jogo no fim da Aula 1:
- Não tem tela inicial nem "aperte espaço" — o Pac-Man já sai andando assim que clica na bandeira verde
- Não tem pontinhos pra comer ainda
- Não tem fantasma, não tem fim de jogo

Essas peças vêm nas próximas aulas.

## Checklist do capítulo

- [ ] O Pac-Man se move para os 4 lados usando setas ou WASD
- [ ] O Pac-Man para de andar (e volta) ao encostar numa parede do labirinto
- [ ] Os dois scripts rodam ao mesmo tempo sem interferir um no outro
- [ ] Ficou claro por que "tocar na cor" resolve a colisão com um cenário desenhado
